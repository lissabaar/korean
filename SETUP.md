# Как запустить проект на новом компьютере

Пошагово, с нуля. Займёт минут 15. База данных уже живёт в облаке (Neon), все
таблицы в ней созданы — на новом компьютере их создавать не нужно.

## 0. Словарь

Словарь KRDict целиком лежит в базе (таблица `KrdictEntry`), он уже загружен
в Neon — на новом компьютере ничего делать не нужно. Обновить его на свежую
версию: скачать «Json 전체 내려받기» на
https://krdict.korean.go.kr/download/downloadPopup, распаковать и выполнить
`npm run load-krdict -- "путь к папке с json"` (несколько минут, таблица
заменяется целиком).

## 1. Что установить

| Что | Где | Зачем |
|---|---|---|
| **Node.js 22 или новее** (LTS) | nodejs.org → Download, обычный установщик | запускает приложение |
| **Git** | git-scm.com | переносить проект и хранить историю |
| **VS Code** + расширение Claude Code | code.visualstudio.com | редактор и я |

После установки Node открой новый терминал и проверь: `node -v` и `npm -v`
должны напечатать версии.

## 2. Перенести проект

Лучший путь — приватный репозиторий на твоём личном GitHub или GitLab:
залить туда проект один раз, потом на любом компьютере `git clone`.

Если без репозитория — заархивируй папку **без** этого:

- `node_modules/` — тяжёлая, ставится заново командой `npm install`
- `.next/` — кеш сборки
- `_import/` — исходные скачанные файлы, в проекте они уже разложены
- `.env` — **секреты, отдельно** (см. ниже)

`.env` никогда не клади в git и не пересылай открытым текстом: в нём пароль от
базы и ключи. Перенеси значения через менеджер паролей или перепиши руками.

## 3. Установить зависимости

В папке проекта:

```bash
npm install
```

Эта же команда сама сгенерирует клиент базы данных (`prisma generate`).

## 4. Заполнить `.env`

Скопируй `.env.example` в `.env` и заполни:

| Переменная | Где взять |
|---|---|
| `DATABASE_URL` | Neon → твой проект → **Connect** → строка подключения (с `-pooler` в адресе) |
| `DIRECT_URL` | та же строка, но **без** `-pooler` в адресе хоста |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys |
| `KRDICT_API_KEY` | krdict.korean.go.kr → 오픈 API → 인증키 (ключ из письма) |
| `STDICT_API_KEY` | необязательно, можно оставить пустым |
| `BETTER_AUTH_SECRET` | любая случайная строка от 32 символов: `npx auth secret` |
| `BETTER_AUTH_URL` | `http://localhost:3000` |
| `UNLIMITED_AI_EMAILS` | твоя почта — для неё ИИ без лимита |
| `FREE_AI_CREDITS` | необязательно: бесплатные кредиты новым пользователям, по умолчанию 50 (= $0.50) |
| `AI_DAILY_BUDGET_CREDITS` | необязательно: общий дневной потолок на всех бесплатных, по умолчанию 300 (= $3) |

Важно: `BETTER_AUTH_SECRET` должен быть **тем же**, что раньше, иначе все
входы в аккаунт сбросятся (не страшно — просто войдёшь заново).

## 5. Запустить

```bash
npm run dev
```

Открой http://localhost:3000 и войди.

Остановить сервер — `Ctrl+C` в терминале.

## Что умеет сайт без регистрации

Сайт открывается сразу, без входа: создаётся анонимный аккаунт. Можно
вписывать слова вручную, взять стартовую колоду, настраивать категории и
повторять. ИИ (разбор текстов, скриншотов, Anki) — только с аккаунтом.
При регистрации или входе всё, что накоплено анонимно, переезжает в аккаунт.

## Категории

Раздел **Categories**: у каждой категории два переключателя — **Learn**
(новые слова берутся отсюда) и **Review** (выученные слова повторяются).
Например, учить только еду, а повторять всё. Там же иконки категорий и
направление повторения (по умолчанию: показывается английский, отвечаешь
по-корейски).

## Вход через Google (необязательно)

1. console.cloud.google.com → создай проект → APIs & Services → OAuth
   consent screen: тип External, название приложения, своя почта.
2. Credentials → Create credentials → OAuth client ID → Web application.
3. Authorized redirect URIs — оба адреса:
   - `https://korean-drab.vercel.app/api/auth/callback/google`
   - `http://localhost:3000/api/auth/callback/google`
4. Скопируй Client ID и Client secret в `GOOGLE_CLIENT_ID` и
   `GOOGLE_CLIENT_SECRET` — в `.env` и в Vercel (потом Redeploy).

Пока ключей нет, кнопки Google просто не видно.

## Что можно загружать

На странице **Add words** — вставить текст или перетащить сколько угодно
файлов сразу (или вставить скриншот через Ctrl+V):

- скриншоты и фото (PNG, JPEG, WebP, GIF; фото с iPhone в HEIC — сначала
  сохранить как JPEG)
- колоды Anki: `.apkg` / `.colpkg`, или экспорт «Notes in Plain Text»
- таблицы `.csv` / `.tsv` — первые столбцы: слово и перевод
- текст `.txt` / `.md`, субтитры `.srt` / `.vtt`

Списки слов можно писать с переводом на любом языке: `눈 — снег`.
Большие файлы делятся на части по 40 строк; процесс можно остановить, и всё
найденное до этого момента останется.

## Шпаргалка команд

```bash
npm run dev                          # запустить локально
npm run build                        # проверить, что всё собирается
npx prisma studio                    # посмотреть базу в браузере
npx prisma migrate dev --name что-то # после изменения prisma/schema.prisma
npx prisma migrate deploy            # применить готовые миграции к новой пустой базе
```

## Если что-то не работает

- **`self-signed certificate in certificate chain`** — сеть перехватывает HTTPS
  (бывает на рабочих компьютерах). В `.npmrc` уже стоит `--use-system-ca`,
  поэтому запускай через `npm run …`, а не напрямую `node`/`next`.
- **Слова помечены «dictionary did not respond»** — словарь KRDict не ответил.
  Это не значит, что слово неверное: просто отправь текст ещё раз. Из
  корпоративной сети он отвечает плохо, из домашней обычно нормально.
- **Сохранение или анализ медленные** — база Neon стоит в Сан-Паулу, чем
  дальше от него, тем дольше каждый запрос.
  Если когда-нибудь переедешь далеко — создай проект Neon в регионе поближе
  и выполни `npx prisma migrate deploy`.
- **`npm` не найден** — перезапусти VS Code после установки Node.
- **`npm.ps1 cannot be loaded because running scripts is disabled`** —
  PowerShell запрещает скрипты. Пиши `npm.cmd` вместо `npm`
  (`npm.cmd run dev`) или переключи терминал VS Code на Command Prompt.

## Работа с Claude на новом компьютере

Память наших чатов хранится локально и на другой компьютер не переедет. Всё
важное записано в `CLAUDE.md` в корне проекта — Claude читает его
автоматически, так что просто открой папку и продолжай.
